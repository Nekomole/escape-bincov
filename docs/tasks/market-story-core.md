## 已实现与边界

- `story.ts` 管永久见闻、小蔡已知事实、喊声选择、本局声音记录以及只读回顾。维修完成节点和供电由原 `repair` 派生。原交付仍扣 3/2/1、奖 420 一次；扩建仍扣 600，样本和船册不变。
- `story-dialogue.ts` 是批准的 18 个固定话题及条件，复用已接受文字；没有新增通用脚本解释器。关闭不等于暂不说；暂不说可改告诉，已告诉不可反悔。未检查总闸只能使用 unchecked 分支，不宣称找到父亲。
- `market-world.ts` 注册 `coast-story-v1 / market-layout-1`，沿用现有居民楼与市场碰撞。只有显式新出击启用；恢复原行动使用原世界/物资/计时。工具柜固定在 (28,37)，不被市场敌人或回收队搬走，43px 内初始普通掉落、箱子、敌人迁到同图合法位置。
- 确定补给在 `D.beginRun` 转移背包之前，统计仓库、背包、安全箱；按缺额占用原始 60 条来源中最先出现的 n 条普通非浅水记录，再归箱。专用柜始终存在；普通箱最多 `min(9, floor((20-n)/2))`，归箱来源≤20，地面来源≥40。样本/船册记录不变。原枪械材料转换、普通物资幸运增减产、敌人携带物规则保留；固定缺额柜本身不掷幸运，保证缺额为零时为空。
- 开柜、冷柜近距触发、总闸主动观察走实际 Runtime 的距离/视线/世界身份检查；线索、本局 cue、活动世界在一笔记录中提交。只有写入成功后产生 `story-cue`。回站前不能向小蔡报告，失败行动保留知识，实物仍按原安全箱/失败规则结算。

一项明确的语义决定：玩家选择“告诉喊声”且确实观察过总闸时，批准对白会亲口说“总闸拉下来了”。因此该明确选择同笔记录 `told` 和 `breakerReported`。这不是把观察自动当报告；unchecked 分支不记录总闸。之后小蔡的知情分支只读确实说过的事实。

## 给 Opus 的接入任务

接续同一分支/PR。可以修改 `station-view`、`coast-view`、`ui.ts`、样式和必要的呈现适配；不要另建任务状态、发奖逻辑、剧情保存键或重写已验事务。

1. 新出击接线：调用原 `HideoutRuntime.deploy({world:'buildings', seed, marketStory:true})`。底层阶段的生产界面没有传这个选项；前端接入后已由院子与旧页签传入（见下节）。经典旧世界和商场不接受该选项。新世界的地图 ID 仍是 `coast`。
2. 小蔡入口：站内 `runtime.story()` 提供供电、缺额、可交付、已报告、选择和见闻；`runtime.openStory(entry)` 返回临时会话，`view()` 给当前文本/按钮，`choose(option.id)` 返回原 Result，`close()` 只关会话。entry 为 start/location/radio/father/breaker/call；内部稳定 ID 不显示给玩家。成功才读下一段，保存失败保留原话题并走现有错误保护；重试保存后用户再点原选择。会话不负责新增暂停豁免。
3. 场景锚点：位置/半径见 `MARKET_ANCHORS`，不增加碰撞。呈现冷柜、配电箱、蔡建平备用柜，第二层指柜内架层；保留原告示原文位置。总闸只观察，不做重新拉闸开关。告示、briefing、powered、report 沿原站内/阅读/供电入口，不虚构为已调查。
4. 行动服务：`CoastServices.story()` 与 `storySources()` 只读；后者给 world/run/map 绑定的 ref、位置、标题与当下可用性。实际 E/触控确认总闸时调用 `observeStory(ref)`，不得因绘制提示/打开回顾就调用。冷柜 72px 近距由 Runtime 自动处理，开柜喊声由原 `activate(containerRef)` 自动处理，无需前端再观察或保存。
5. 声音/字幕：消费带 `durability:'committed'` 的 `story-cue`，按事件 seq 去重。事件给 source/clue/text/sound；文本与只读回顾包含全部线索，静音不丢信息。危险信息优先，剧情最多一条，丢弃过时字幕，不排长队。恢复检查点不会重播；同一新局允许再次听到，但永久见闻不重复追加。
6. 输入/生命周期：Esc、触控关闭、失焦、死亡、超时、换页、冲突均关闭相应面板、释放输入和会话引用；保持现有世界时钟规则。读回顾不生成证据、不扣物、不默认选择。柜子取物继续原 transferLoot，禁止前端直接改两端库存。
7. 前端完成后再启用默认市场出击入口并做 1280×720、1920×1080、手机横屏、音量零、遮挡/危险消息、刷新恢复、两条自然路线和真人理解验收。不要仅凭本页底层测试把 #83 关闭。

## 前端接入（Opus，2026-11-01）

只用上面的接口；没有新增任务状态、发奖、剧情存档键或事务。源码入口见 [CODEMAP](../CODEMAP.md) 的市场一行。

**默认入口。** [raid-areas.ts](../../src/raid-areas.ts) 的 `marketStory(world)` 是唯一规则：沿海街区的新出击带 `marketStory:true`，院子出击面板（`StationHooks.marketStory`）与旧页签 `deploy` 共用。商场、已在途的旧街区和经典行动不变。

**站内小蔡。** 电台面板右侧加「小蔡」卡片（窄屏放最前）：「和小蔡说话」「见闻 N 条」。看过总闸还没报告、或听到喊声还没选择时显示「有事可说」；选了“暂不说”不再提示。对话页的对话框尺寸固定：话题名（打开时定下，中途不变）、台词、预留的一行错误提示、选项；下方六个话题按钮位置固定：问小蔡／供电怎么样？、工具柜在哪？、电台怎么回话？、你父亲？、市场的事／总闸的事、还有件事。／喊声的事（没听到喊声时这一格留空、不可点）。最下面两行只读：维修单缺额、值班册（只写确实说过的：报告后“市场总闸已拉下。”，告诉后“配电区听到喊声，没有见到人。”）。

- 只有 `choose()` 写入成功才显示下一段。失败时保持原话题和选项，错误行写“没有记下：…”，并打开原存档失败对话框；重试保存后玩家再点同一选项。关闭面板、Esc、切到任务或见闻页都只调用 `close()`，不替玩家选。切出窗口、页面隐藏或离开页面（`blur`、`visibilitychange` 隐藏、`pagehide`）同样结束对话：释放会话（包括供电动画期间暂存的那次），对话框原位回到话题列表；回来时的按键或松开鼠标落不到原来的回答上。
- 对话里的“交付物资”走原 `submitQuest` 事务。供电动画期间院子暂存这次对话，动画结束回到电台显示原电台广播和老栓那句；奖励只发一次。任务卡上原来的交付按钮不变。

**行动内。**

- 场景（[art/market.ts](../../src/coast-view/art/market.ts)，`CoastView.dressMarket`）：旧冷柜 (23,39)、靠东墙的配电箱 (29,40)（闸刀在下，闸柄上有盐，门开着）、配电区地面虚线（x=27），工具柜画成蔡建平的铁皮柜（关门／开门时第二层是报纸包／搜空）。都没有碰撞。新世界的地图标出“工具柜”（维修单写明的位置）。
- 总闸：`storySources()` 说可检查时提示「E 检查 · 配电箱」，触屏交互键显示「检查」，配电箱描边。和 Runtime 的目标同时在范围内时按距离比，平局按稳定 ID；附近列表两项都列出，滚轮或点击可切换，触屏点名称直接执行。只有真正按 E／点按才调用 `observeStory`；画提示、打开见闻都不调用。出口的按住撤离不会被抢走。
- 字幕：只处理 `durability:'committed'` 的 `story-cue`，沿用宿主按事件 seq 去重。一次一条，新的替换旧的；电台预警、红色失败提示或受击时让开，让开期间到时的字幕直接丢掉，不排队，内容留在见闻里。桌面在按键栏上方居中，触屏在左下；背包或搜刮面板打开时放到面板上方；手机上搜刮面板占满屏时只盖面板左上的标题块，不挡危险信息行和关闭按钮。
- 声音（`SynthAudio.knocks` / `call`）：冷柜两下闷响，配电区方向一段远处含混的喊声（合成，没有词），按锚点定位声像。音量为零时字幕和见闻信息不变。
- 见闻：右上「见闻 · N」按钮或 J 键，打开阻塞面板，世界照常运行（同原阅读面板）；E、J、Esc、失焦都会关闭，行动结束不留面板。新世界的任务卡里“让灯亮起来”下多两行：维修单原话的位置，以及总闸“可选／已确认，回站可以告诉小蔡／小蔡已记下”。

**跟随 #170 的统一样式（2026-11-02）。** 合入 main `33adc85b`（#163 第二批）后，院子的小蔡卡片、对话页、见闻页，以及行动内的字幕和见闻面板，都改用 [ui-tokens.css](../../src/ui-tokens.css) 的变量：背景按原明度归到 `--ui-n1`–`n3`，台词和见闻正文用 `--ink`（n14）；行动字幕左边线原来是卡其色，现在改成统一的琥珀色 `--cs-accent`。桌面上原来 11px 的小字提到 12px，小字和正文用系统字，像素字只用在 16px 的标题上。电台面板改用共用的居中框（距窗口 12px，大窗口 5vh 5vw）。任务、小蔡、见闻三个子页和其他文字页签一样，最宽 1080px、居中，切换子页时框不变；对话框高度仍固定 248px。手机布局没有改。地图上工具柜的标记原本就是 `#e2b45c`，也就是 `--ui-a`。随后又合入 main `2b3fd7e9`（#171 任务物品绿框），工具柜里的泵机零件、绝缘线圈、陶瓷保险管在维修交付前也显示绿框。
