## 问题

2026-10-31 在 main `278b7e24` 上用真实打包版本截了 1280×720、1920×1080、844×390、390×844 四个尺寸（标题、院子七个页签、改枪台、旧页签、行动 HUD 与背包），并量了面板宽度、格子和字号：

6. **各画面各一套颜色。** 标题、院子、行动、改枪台、旧页签各有一套颜色变量，强调色分别是 #c09a55、#e2b45c、#c9a65e、#c7ba8c、#c6d58b；`style.css`、`station.css` 各有约 180 个写死颜色。院子面板有 10–11px 的字，旧页签把 Consolas、像素字（12/14/24px 等非原生尺寸）和系统字混在同一面板。

## 实现

只改显示，不碰规则、存档和输入。

1. **共用变量** [ui-tokens.css](../../src/ui-tokens.css)，页面最先加载，院子的 shadow root 经宿主继承：
   - 颜色是 `r g b` 三元组，写成 `rgb(var(--ui-n3))` 或 `rgb(var(--ui-n3) / .9)`。`--ui-n0…n15` 是按 OKLab 明度排的 16 阶中性色（暗阶偏墨绿、亮阶偏暖，取自院子）；`--ui-a-*` 是唯一的强调色（院子琥珀 #e2b45c / #ffd88a 及深浅阶）；`--ui-b/g/i-*`、`--ui-w` 是坏、好、信息、警告。
   - 各样式表原有的写死颜色按所属画面原来的色系归到最近的明度阶（中性色）或同色相的阶（强调、状态色），所以院子、改枪台、出击选图基本不变，旧页签的黄绿、行动的卡其、标题的黄铜统一成琥珀。各文件原有的局部变量（`--ink`、`--cs-*`、`--gs-*`、`--t-*` 等）保留名字，值改为引用共用变量。
   - 只有纯黑白阴影/高光保留字面值；行动里的战斗特效色（受击方向、击杀标记、受伤暗角、上限变化）收成 `.coast-sample` 上的具名变量。序幕是美术，不在范围内。
   - 字体：`--ui-px`（像素字，只用原生 16 / 32px：面板标题、小节标题、页签、物品名、关键数字）、`--ui-sys`（系统字：正文、说明、按钮、小标签和小数字，用等宽数字）；字号 `--ui-fs-s` 12px 起；间距 `--ui-sp1…5`。
2. **字号与字体角色**：桌面端小于 12px 的字一律提到 12px（手机专用规则不变）；`small` 默认 12px。旧页签去掉 Consolas：16px 以上的数字用像素字，小数字用系统字；页面继承像素字，小于 16px 的按钮和说明改系统字；24 / 22 / 18.72px 的像素字标题改 16px。院子台账数字 15px、改枪台标题 17 / 15 / 14px 改 16px，出击页的英文小标从 monospace 改系统字。
3. **固定面板框**：院子七个页签（含出击）都用出击原来那个居中框——距窗口 12px，1500×850 以上 5vh 5vw——标题栏和页签栏位置一致，切页签不再改变框。框盖住院子，相机不再为停靠面板让位（删掉 `panelInset`）。格子和商店在框里居中；任务、设施、身体等文字面板最宽 1080px 居中。出击页的标题栏也换成和其他页签相同的样式。
4. **格子随屏幕放大**：院子按框的尺寸算格子，上限 56 → 88px（`frameBox` / `cellFor`）；商店右栏宽度按格子固定（仓库列数 × 格 + 62px），交易单文字变长也不挪格子。旧页签商店四个格子按窗口算（`shopCell`，54–80px）；行动背包在 1000px 高以上为 72px。物品图本来就按格子整数倍放大。
