# 三分支技能正式接入计划（#143）

2026-10-29，维护者转达开发者讨论已一致决定将三分支技能接入游戏，并采纳 [PR #148](https://github.com/xuys2025/escape-bincov/pull/148) 审阅意见。本页把该决定转为后续开发与验收计划；实现范围和当前完成情况分别记录。原始提案、讨论及总验收由 [#143](https://github.com/xuys2025/escape-bincov/issues/143) 承接。

当前已完成的是 [48 项候选的研究实现](skill-tree-research.md)及压弹材料保护调整；正式 Runtime、角色迁移、技能界面和真人平衡尚未接入。继续使用原 PR #148 分阶段交付，不另开同目标 PR。若维护者先合并研究阶段，再启动正式接入，应先在 #143 记录研究阶段的合并结果和剩余范围，再建立后续承接关系；本次决定不等于已合并、已上线或已批准跳过检查。

## 已确定的开发约束

1. 保留力量、体质、技巧基础成长；新树使用战斗、生存、搜索独立 XP 与专用点，不重复发通用点。每支 15 点、5/10 点门槛、2 点机制节点和专精各自二选一作为开发对照基线。48 项全部进入作用点与验收清单；需要替换或删减时回到 #143 明确决定，不默默缩减为少数样板技能。
2. 压弹默认不消耗材料。玩家指定物品及最多消耗数量后才可执行；任务所需数量优先保留，救济和显式保护物品不能使用。回收产生或后来合堆的零件不自动扩大已批准数量。使用真实名称“泵机零件”，显示投入、产出、限额及支持的弹药，不把有价值物资叫作无用废料。
3. 旧角色默认保留现有属性和 Perk，进行中的旧行动按自己的规则完成。正式转换采用据点内可预览的自愿流程；逐项权益与补偿表通过前，不提供转换按钮。一个角色同时只启用一套技能选择效果，不能重复叠加旧 Perk 和新树。
4. 新角色在正式版本验收后使用新树。技能只在据点确认、保存成功后生效；本局使用出击时冻结的配置，行动内获得 XP 不改本局技能。死亡、超时、放弃保留已成功保存的成长，原物资损失规则不变。
5. 角色、世界、技能、物资及事件入账标记共同提交到现有 SaveSession。不能加第二个存档 writer，不能在保存后的展示通知里另补经验。未知/损坏数据拒读，保留原始备份、多窗口保护、待结算重试和单文件离线能力。
6. 研究日志回放只作为规则对照工具。正式运行改为有限累计账本和检查点，不逐帧重放整局历史，也不逐次命中写 localStorage。
7. 当前数值继续作为可调整参数。经验曲线、掉书率、重配费、自动回复与转换收益要经两图实玩后定稿；“各分支每局速度相同”不是未经验证的承诺。采样使用测试工具或玩家自愿导出的本地摘要，不增加联网遥测。

## 本轮已落地的压弹修订

研究资源格式升为 **v2**，技能进度和经验研究格式仍为 v1；这些均不是正式游戏存档版本。资源 v1 因自动消耗语义变化明确拒读，不能按新规则静默重新解释旧实验日志；旧实验原文件应保留，正式玩家存档不受影响。

- 出击种子必须带经过严格校验的 `completedQuests`，由未来的状态拥有者从档案生成。当前研究按未完成任务的完整需求在背包中保守保留普通材料；供电任务未完成时，至少保留 3 个普通泵机零件，救济零件不抵扣此保留量。不读取仓库来降低保留量。
- `approve-press` 指定具体堆 UID 和 0～3 个材料，0 表示撤销；多堆批准量合计不能超过剩余任务外材料或本局剩余制作预算。每次成功转换才扣一份批准量，满包失败不扣材料或批准量；重复命令和读档不重新授权。
- 仍只制作 9 毫米弹、卡宾枪弹、霰弹，支持当前 20 枪中的 14 把。M1911、UMP45、P90、SVD、M14、M700 不适用；不支持时不消耗材料。自动续装是另一节点，已有全部 20 枪覆盖。
- 每份泵机零件卖价 35，换出两发基础弹药卖价为 6/10/14；电池卖价 75，回收成零件卖价 35。此为当前领域数据的成本示例，正式 UI 从同一数据源生成预览，不另抄一套价格。后续需与 #80 的经济调整复核。

原版“3 个任务零件在第 42 秒变成 6 发手枪弹”的失败断言已经保留在资源测试中。保护后的规则还覆盖任务完成、剩余材料、撤销、多堆超额、救济/保护物品、满包回滚、读档重试以及全部枪种的适用性。

## S0 必须解决的具体口径

- **旧权益不能按选择数量粗略折算。** 现有负重可合计 +10 kg，新普通负重仅 +3 kg；常驻换弹可到 ×0.68，新普通换弹 ×0.88、击杀条件 ×0.704。生命上限、常驻暴击、屏息和暴击伤害等差异逐项列出。补偿根据旧档可验证数据，不伪造历史行为 XP，不让先重置旧选择的人少获补偿。旧角色默认保留方案解决继续游玩，未解决的补偿数值仍需定稿。
- **经验归属按真实事实。** 击杀确认归属玩家且生命由正数降到零；区分精英/头目/动物/友军/NPC 互杀、近战、霰弹、追击和跨层。同一次流血有稳定身份；食品与自动回血不训练医疗，也不能留下创伤额度让后续医疗重复训练。
- **有效活动需可解释且有限。** 暂停、离线、原地不计；窗口内新路线推进或有效战斗/首次搜索可以计入。不能仅把“移动了”或旧的 64 像素锚点当成防挂机证明。两图探索奖励使用独立可达白名单，不直接按 8/39 个空间 region 全量发奖。
- **48 项逐项落点。** 控枪明确 kick/bloom/固有散布、精瞄与腰射的边界；重量区分材料、药品与枪械及所有携带位置；普通走路当前不产生 AI 听觉噪声，“安静搜索”必须明确改冲刺噪声还是另改设计；材料提示、记忆和扫描不得伪装成新物资或透视。纯升级加速的“分类记录”需评估满级后的用途，保留/替换须明示。
- **主动操作与消耗预览。** 扫描及材料授权有可触达的桌面/触屏界面入口，不默认增加新快捷键；压弹显示支持弹种、预计消耗、任务保留和可取消的数量。应急包扎用一份绷带仅回 10 HP、普通绷带基础 16 HP；代谢回复消耗水/饱食，这些取舍必须可见。具体动作布局随 S5 验证。
- **冻结与格式升级。** 正式 session/行动格式按实施时最新主线决定，不预占版本号；资源研究 v2 不能塞进正式可选字段。当前研究的任务保留只看出击时完成事实和背包，正式版在候选事务中重新校验当前任务需求、指定堆的现存数量及批准余额；拾取、拆并、转移不会扩大授权，失效来源撤销或明确重选。
